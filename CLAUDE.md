## Project Overview

This is the MeshVPN project, a self-hosted, containerized mesh VPN platform that runs across multiple nodes. The system uses OpenVPN over TCP 443 for client connections and WireGuard internally between nodes. It features leader election, automatic failover, and Cloudflare DNS integration for dynamic routing.

## Build Plan and Development Workflow

The project is built in 7 phases, with each phase producing a runnable system:

1. **Phase 1: Scaffold** - Create repository structure, docker-compose.yml, mesh.yaml.example, and basic core service
2. **Phase 2: Leader mode** - Node A initializes, API works, frontend loads login page
3. **Phase 3: Join logic** - Node B joins Node A, appears in dashboard
4. **Phase 4: Health + failover** - Kill Node A, Node B takes over automatically
5. **Phase 5: Frontend complete** - All four pages work, client .ovpn downloadable
6. **Phase 6: Raspberry Pi** - Same compose file works on ARM
7. **Phase 7: Hardening** - E2E tests pass, iptables rules applied, secrets secured

## Key Technologies

- **Backend**: Python 3.12 with FastAPI
- **Database**: SQLite via standard library
- **Configuration**: Pydantic v2 for validation
- **Templates**: Jinja2 for config generation
- **Frontend**: React + Vite
- **Containerization**: Docker Compose

## Development Commands

To work with this project:

1. **Build and run all services**: `docker compose up`
2. **Build and run with specific services**: `docker compose up core wg-manager router`
3. **View logs**: `docker compose logs [service-name]`
4. **Stop services**: `docker compose down`
5. **Rebuild images**: `docker compose build --no-cache`

## Node States and Election

The system implements a bully election algorithm:
- **LEADER**: Primary node managing the mesh
- **FOLLOWER**: Secondary node replicating configuration
- **CANDIDATE**: Node attempting to become leader
- **ISOLATED**: Node unable to communicate with others

## Important Notes

- All services run in containers with proper network isolation
- WireGuard configuration is generated via templates and applied via `wg syncconf`
- OpenVPN server configuration is generated via Python templates
- Cloudflare DNS updates are handled by the dedicated Cloudflare service
- Authentication uses JWT tokens with bcrypt password hashing
- The system supports both leader and join modes in mesh.yaml configuration
